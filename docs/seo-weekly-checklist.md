# SEO weekly checklist (AWS Vision)

Use this every week. Do not buy links or create fake citations.

## Monday — Search Console

- [ ] Open [Google Search Console](https://search.google.com/search-console) for `awsvision.com`
- [ ] Check **Coverage / Pages** for new errors
- [ ] Request indexing for any new URLs (city pages, guides) still “Discovered / not indexed”
- [ ] Note top queries under **Performance** (impressions vs clicks)

## Wednesday — On-site

- [ ] Confirm sitemap: `https://awsvision.com/sitemap.xml` loads
- [ ] Spot-check 2 city pages + 1 guide (title, H1, internal links)
- [ ] Add 1 internal link from an older page to a new guide if missing
- [ ] Update rates/FAQ if product terms changed

## Friday — Outreach (real only)

- [ ] Send **1–2** outreach emails from `docs/backlink-outreach.md` (personalize first)
- [ ] Log replies in a sheet: date · site · status · URL if published
- [ ] Never: PBN, link farms, fake directories, fake Google reviews

## Monthly

- [ ] Publish or refresh 1 guide / FAQ
- [ ] Re-submit sitemap if many URLs added
- [ ] Review Texas + US service pages for accurate “no retail branch” wording
